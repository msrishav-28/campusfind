# Build sequence

## Week 0

Walk Kengeri. Replace `data/kengeri/places.json` coordinates at each door. Write Help copy. Agree Block I as desk.

## Week 1

Next.js App Router. `app/[campus]/page.tsx`. MapLibre. Seed pins from JSON. Report sheet: photo + Web Speech + place snap. Local or seed-only items acceptable if Supabase is not ready by Friday.

## Week 2

Supabase schema + RLS-via-server. Photo upload, EXIF strip, session cookie, permalinks.

## Week 3

Claims + secret hash. Expiry cron. Share OG. Abuse report. Optional interpret if `GEMINI_API_KEY`.

## Week 4

Desk list + PIN. Rate limits. Analytics. Soft launch: Engineering + hostels only.

## Then v1.1

Gemini tags on every upload. Embeddings. Top-3 matches. Whisper retry.

## Then v2

Notify. Real desk role. Footprints / nav deep-link. Door QR. `/central` after a walk.

## Definition of done (v1)

On a mid-range Android at Block IV cafeteria:

1. Map in < 3 seconds.
2. Found post: photo + spoken sentence + snapped place, no account.
3. WhatsApp link opens that pin.
4. Another student claims with private detail.
5. Pin leaves open after 14 days.
6. Gemini unset or down: post still succeeds.
