# Kengeri facts for engineers

- Name: CHRIST (Deemed to be University), Bangalore Kengeri Campus
- Plus Code: VC7Q+75
- Centroid: 12.86285, 77.43812
- Fence: 700 m (tune after walk)
- Size: about 78 acres — GPS + named places is the right resolution
- Desk: Block I security (confirm on the walk)
- Hostels: Devadan Hall (men), Christ Hall (women)
- Academic: Block I–IV, Central Block, Campus Library (often spoken as Block IV library)
- Food: Block I cafeteria, Block IV cafeteria
- Do not use Block A/B/C from the old site
